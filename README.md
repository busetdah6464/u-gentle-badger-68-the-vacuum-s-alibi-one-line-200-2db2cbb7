# The Vacuum's Alibi: One Line, 200 Characters

Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun.

One line, at most 200 characters: the excuse a robot vacuum gives for
missing a spot. Mine claims it did not miss anything — its sensors
classified the spot as a permanent resident, and it does not evict tenants
without a court order. Deadpan robot voice, a surprise turn, and a tight
landing in a single sentence.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
